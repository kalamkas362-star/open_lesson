# Noto Sans — local Kazakh web font

Source: [Google Fonts / Noto Sans](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/notosans), pinned to commit `47d54ca1ebb14fd864695f1d39dc734f39017c33`.

Original file: `ofl/notosans/NotoSans[wdth,wght].ttf`, downloaded over verified HTTPS. Source SHA-256: `bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.

`noto-sans-kazakh-variable.woff2` was prepared with FontTools 4.61.1: subset the Latin/Cyrillic character ranges and the site's existing text, fix the width axis at its default 100, then compress to WOFF2. The weight axis remains variable from 100 to 900. It contains 1,452 mapped characters, including every uppercase and lowercase Kazakh-specific letter: Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі. CSS declares the unique family `Lesson Noto Sans` so locally installed fonts cannot mask whether the website file loaded.

Generated WOFF2 SHA-256: `4a96f820b0aea34c13b0ad989e95265a5433759e1155db24de9574e366baadbe`.

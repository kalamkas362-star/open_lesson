# Қазақстан экономикасының дамуы — интерактивті ашық сабақ

ҚМЖ негізінде әзірленген, қазақ тіліндегі 5 экраннан тұратын интерактивті сабақ сайты.

## Файлдар

- `index.html` — сабақтың бес экраны мен тапсырмалар.
- `style.css` — поп-арт карточкалар, түстер, орналасу және мобильді бейімдеу.
- `script.js` — экрандар навигациясы, сәйкестендіруді тексеру, хатты көшіру/сақтау және QR-сілтемесін баптау.
- `.nojekyll` — GitHub Pages жариялауына арналған белгі.

## Экрандар

1. **«Суреттер сөйлейді»** — екі аударылатын стратегия карточкасы және бейнероликке Play сілтемесі.
2. **«Интеграция»** — экономиканың даму кезеңдерін сәйкестендіру. Ең жоғары ұпай: 3 балл; ҚМЖ бойынша уақыт: 10–12 минут.
3. **«Стратегиялық карта»** — «Қазақстан 2030», «Қазақстан 2050» және «Мәңгілік ел» топтары. ҚМЖ дескрипторлары бойынша ең жоғары ұпай: 4 балл; уақыт: 10 минут.
4. **«Болашаққа хат»** — «Менің Қазақстаным: 2040 жылғы болашаққа хат». Оқушы хатты браузерде жазып, көшіріп не мәтіндік файлға сақтай алады. Бағалау: 3 балл; жоспардағы жеке тапсырма кезеңі үшін уақыт ретінде 5 минут көрсетілді.
5. **«Референдум»** — кері байланыс сұрақтары және QR-код. Мұғалім ботқа немесе формаға апаратын URL мекенжайын өзгерте алады.

## Жергілікті іске қосу

`index.html` файлын браузерде ашыңыз. QR-кодты динамикалық жасау үшін интернет байланысы қажет (QRCode.js CDN).

## GitHub Pages арқылы жариялау

1. Осы репозиторийде **Settings → Pages** ашыңыз.
2. **Build and deployment → Deploy from a branch** таңдаңыз.
3. Branch ретінде `main`, folder ретінде `/(root)` орнатып, **Save** басыңыз.
4. Біраз уақыттан кейін сайт `https://kalamkas362-star.github.io/open_lesson/` мекенжайында ашылуы тиіс.

## QR-код ескертпесі

ҚМЖ-да нақты Telegram-бот немесе сауалнама сілтемесі берілмеген. Сондықтан бастапқыда QR `https://t.me/` сілтемесін қолданады. Сабаққа дейін QR батырмасы арқылы өз формаңыздың нақты сілтемесін енгізіңіз.

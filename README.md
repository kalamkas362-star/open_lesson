# Қазақстан Республикасының экономикасының дамуы

11 «Ә» сыныбына арналған, қазақ тіліндегі бес экранды интерактивті сабақ. Сабақ күні: 20.10.2026. Мазмұнның негізгі дереккөзі — «ҚМЖ Олимпиада Бермаганбет.docx» соңғы нұсқасы.

## Жергілікті іске қосу

Тәуелділіктерді орнату және жинақтау қажет емес. Python 3 бар компьютерде:

```sh
cd open_lesson
python3 -m http.server 8000 --bind 127.0.0.1
```

Браузерде серверді ашыңыз. `index.html` файлын тікелей ашу да мүмкін, бірақ браузердегі сақтау және көшіру мүмкіндіктерін тексеру үшін HTTP арқылы іске қосқан дұрыс.

Суреттер, стильдер, сценарий және QR кітапханасы репозиторийде сақталған. Сайттың негізгі мүмкіндіктері сыртқы CDN мен веб-қаріптерге тәуелді емес. YouTube бейнесін және Telegram-ботты ашуға интернет қажет.

## Сабақ экрандары

1. **«Суреттер сөйлейді»** — оқу мақсаттары, екі жеке эмблема-карточка және ҚМЖ-дағы YouTube бейнесіне сілтеме. Карточкалар бір-біріне тәуелсіз айналады.
2. **«Интеграция»** — алты сипаттаманы үш кезеңге орналастыру. Компьютерде тышқанмен сүйреңіз; телефонда A–F әріп белгісінен ұстап сүйреңіз немесе карточканы басып, қажетті ұяшықты түртіңіз. Пернетақтада Tab және Enter/Space пайдаланыңыз. Дұрыс кезеңге 1 балл, барлығы 3 балл. Уақыты: **5 минут**.
3. **«Стратегиялық карта»** — «Қазақстан 2030», «Қазақстан 2050», «Мәңгілік ел» топтары. ҚМЖ картасындағы алты бөлім, талқылау сұрақтары және постерге ұсыныстар. Бағалау: **4 балл**, уақыты: **12 минут**.
4. **«Болашаққа хат»** — сөз санау, браузерде автоматты сақтау, көшіру және UTF-8 `.txt` файл жүктеу. Бағалау: **3 балл**, уақыты: **5 минут**. Хат серверге жіберілмейді; ортақ компьютерде жұмысты аяқтаған соң мәтінді өшіріңіз.
5. **«Референдум»** — кері байланыс сұрақтары, толық түпнұсқа QR және Telegram-ботты ашу батырмасы. Уақыты: **5 минут**.

## ҚМЖ бойынша сәйкестендіру

Жауап кілті: **1 — A/D; 2 — B/C; 3 — E/F**. Кезеңдер: 1991–1994, 1995–1999, 2000 жылдан бүгінге дейін.

Сипаттамалар мен кілт соңғы DOCX инфографикасынан сақталды. Дереккөзде B сипаттамасындағы ұлттық валютаның енгізілуі (1993 ж.) екінші кезеңге (1995–1999) сәйкестендірілген. Бұл хронологиялық қайшылықты мұғалім сабаққа дейін нақтылауы керек; сайт оны өздігінен өзгерткен жоқ. Топтық картаға талқылау сұрақтары мен қысқа ұсыныстар қосылды; олар ҚМЖ-ның тікелей дәйексөзі емес.

## Файлдар

- `index.html` — бес экранның құрылымы, тапсырмалар және сілтемелер.
- `style.css` — ашық түсті дизайн, 3D карточкалар, телефонға бейімдеу.
- `script.js` — навигация, сәйкестендіру, хат және QR баптауы.
- `assets/` — суреттер және жергілікті QR кітапханасы.
- `.github/workflows/deploy-pages.yml` — `main` өзгергенде GitHub Pages жариялау workflow-ы.

## GitHub Pages

Осы **open_lesson** репозиторийінде **Settings → Pages → Build and deployment → Source → GitHub Actions** таңдаңыз. `.github/workflows/deploy-pages.yml` дайын сайтты жариялайды; бөлек жинақтау қадамы жоқ.

Өзгерістер `main` тармағына жіберілген соң [Actions](https://github.com/kalamkas362-star/open_lesson/actions) ішіндегі жариялау нәтижесін тексеріңіз. `queued`, `waiting` немесе сәтсіз орындалу жариялаудың аяқталғанын білдірмейді.

Жоспарланған мекенжай: `https://kalamkas362-star.github.io/open_lesson/`. Сайттың жарияланғанын тек workflow сәтті аяқталып, мекенжайдағы жаңартылған мазмұн ашылғаннан кейін растаңыз. `History_detective` — бөлек жоба.
